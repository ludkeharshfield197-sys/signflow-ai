# 无界手语 SignFlow AI：商业化产品定位

## 产品定义

无界手语 SignFlow AI 是一套面向公共服务、医疗导诊与特殊教育场景的多模态手语沟通平台。它将摄像头、图片和视频输入转化为结构化识别结果，并通过场景策略、语音朗读、沟通协助卡与双向确认完成一轮可复核的服务沟通。

产品对外只呈现用户问题、产品能力和服务价值，避免临时项目式表述。

## 核心价值

- 看得见：支持中文手语与英文手语模型切换，展示模型版本、词级置信度和处理耗时。
- 听得懂：把识别结果组织为可朗读、可复制的自然语言句子。
- 能确认：结果进入后续流程前，由沟通双方确认含义；存在歧义时可请求重新表达。
- 可衔接：根据政务、医疗和教育场景生成沟通建议与本机协助卡。
- 可追溯：保留输入类型、场景、模型和确认状态等技术上下文，便于复核。

## 产品信息架构

1. 官网：解释产品价值、能力边界、适用场景与数据使用方式。
2. 产品导览：使用明确标注的授权样例，展示从输入到确认的完整流程。
3. 识别工作台：承载摄像头、图片、视频输入，支持模型、场景和识别预设切换。
4. 结果中心：保存识别句子、分词、置信度、技术上下文和确认状态。
5. 数据洞察：聚合任务量、处理速度、完成率与模型使用情况。
6. 管理后台：管理用户、角色、模型服务状态与系统依赖。

## 对外表达原则

- 强调“沟通闭环”，不把单次模型输出包装为最终结论。
- 明确区分官方样例、真实上传内容与模型评测数据。
- 不以未经公开评测的数据宣称行业领先或替代人工服务。
- 不默认将体验内容写入训练集。
- 以服务流程、可信确认和可扩展部署体现技术深度。

## 推荐演示路径

打开产品导览，选择官方样例与服务场景，进入工作台切换中文或英文手语模型，完成一次识别；展示句子、分词和置信度后，朗读结果并生成沟通协助卡，最后执行“确认含义一致”或“请求重新表达”。整条路径聚焦真实服务流程，不需要额外解释产品来源。
